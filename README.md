# 🌿 AI Botanical Identification System – Text to Plant

An AI-powered botanical identification system that helps users identify plant species using textual descriptions, plant images, and voice input.

🔗 **Live Demo:** https://text-to-plant-phi.vercel.app/

🔗 **GitHub Repository:** https://github.com/Jagadishjm-git/Text_To_Plant

---

## 📌 About the Project

The **AI Botanical Identification System** is designed to make plant identification easier and more accessible using Artificial Intelligence (AI).

Users can provide information about a plant through its physical characteristics, upload a plant image, or describe it using voice input. The system analyzes the provided information to help identify the corresponding plant species.

This project aims to combine AI-based plant identification with an interactive and user-friendly web interface.

## 🎯 Project Objectives

- Develop an intelligent plant identification platform.
- Identify plants using textual descriptions.
- Support image-based plant identification.
- Enable voice-based plant descriptions.
- Provide an accessible botanical information system.
- Demonstrate practical applications of AI in botanical research.

## ✨ Key Features

🌱 **1. Text-Based Plant Identification**
- Enter plant characteristics and descriptions.
- Analyze the provided textual information.
- Identify matching plant species.

📸 **2. Image-Based Plant Identification**
- Upload plant or leaf photographs.
- Supports PNG, JPG, JPEG, and WEBP formats.
- Analyze visual plant characteristics.

🎙️ **3. Voice-Based Identification**
- Provide plant descriptions using voice input.
- Supports hands-free interaction.

🌿 **4. Sample Plant Descriptions**
- Neem Tree
- Holy Basil (Tulsi)
- Aloe Vera
- Mango Tree
- Pomegranate Tree
- Turmeric

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **AI / Machine Learning:** Plant identification and analysis
- **Database:** Project database
- **Dataset:** Plant_Dataset_with_Full_Descriptions.xlsx
- **Deployment:** Vercel

## 🏗️ System Workflow

1. User provides a plant description, image, or voice input.
2. The system receives the input.
3. The input is processed and analyzed.
4. The identification engine evaluates the available plant information.
5. The system generates the plant identification result.
6. The result is displayed through the web interface.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Jagadishjm-git/Text_To_Plant.git
```

### 2. Open the Project Folder

```bash
cd Text_To_Plant
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

Install the dependencies specified by the project in your `requirements.txt` file.

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python main.py
```

Open the local application at:

```text
http://127.0.0.1:5000
```
